# Taksin Raja - Portfolio Website

Welcome to my portfolio website repository! This is the personal portfolio I created to showcase my projects, skills, and experience as a Web Developer and UI/UX Designer.

![Portfolio Preview](https://taksinraja.netlify.app/)

## 🌟 Features

- **Responsive Design**: Optimized for all devices (mobile, tablet, and desktop).
- **Avout Section**: Here i add about me.
- **Projects Showcase**: A dedicated section for all my web development projects.
- **Skills Section**: Highlights my expertise in various technologies.
- **Interactive Design**: Smooth transitions and user-friendly UI for better experience.
- **Contact Form**: Integrated form to get in touch for collaborations or inquiries.

/portfolio
├── index.html          # Main HTML file
├── about.html          # About me HTML file
├── hireme.html         # Hire me HTML file
├── mywork.html         # My Projects showcase HTML file
├── skills.html         # My Skills showcase HTML file
├── 404.html            # Not found (Error) HTML file
├── README.md           # Project documentation
└── assets/             # Images, icons, and media files


## 🛠 Technologies Used

- **HTML5** - Structure and layout of the website
- **CSS3** - Styling and responsive design
- **JavaScript** - Interactive elements and functionality
- **Figma** - UI/UX design mockups
- **GitHub** - Version control and repository hosting
